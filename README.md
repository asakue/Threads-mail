# Threads // Почта без шума как переписка

> **«Почта, которая читается легко и спокойно, как переписка, но работает поверх ваших существующих ящиков Gmail и Яндекс.»**

Проект представляет собой клиент электронной почты нового поколения:
- **Чистый фокус на чтении:** всего два главных экрана — лаконичный список диалогов и воздушный тред сообщений без громоздких панелей.
- **Никаких мыльных баблов:** сообщения представлены чистым типографическим потоком, без огромных белых прямоугольников и разноцветного шума.
- **De-clutter Engine:** интеллектуальная срезка канцелярита, юридических дисклеймеров и сворачивание цитат в аккуратные ссылки.
- **Zero-Knowledge Backend:** сквозная безопасность без сохранения приватной переписки на промежуточных серверах.

## Архитектура монорепозитория

```
ладк/
├── packages/
│   ├── shared/    # Общие типы, Zod схемы и De-clutter Engine (срезка канцелярита и цитат)
│   ├── backend/   # Fastify v5 API, шлюзы Gmail/Яндекс, AES-256-GCM шифрование токенов и телеметрия
│   ├── client/    # React 19 + Vite + Tailwind: Clean 2-column desktop (collapsible rail) + Mobile Shell (Full-width)
│   ├── desktop/   # Нативное десктопное приложение Electron (Windows/macOS)
│   └── mobile/    # Мобильный проект React Native (Expo) с локальной базой данных WatermelonDB
├── code_artifact.html  # Интерактивный UI Flow & Design System Board (референс дизайна)
└── package.json        # NPM Workspaces конфигурация
```

## Быстрый запуск

### 1. Запуск бэкенда
```bash
npm run server
```
Сервер запустится на `http://127.0.0.1:3001` и подключит очереди синхронизации.

### 2. Запуск веб / мобильного клиента
```bash
npm run client
```
Клиент доступен в браузере: `http://localhost:5173/` (с авто-проксированием API на бэкенд).
- **Desktop вид:** 2-колоночный интерфейс с плавным сворачиванием бокового меню в иконки (`Ctrl+B`).
- **Mobile вид:** полноэкранный интерфейс с поддержкой Safe Area, свайпами и навигацией.

### 3. Запуск нативного десктопного приложения (Windows)
```bash
npm run desktop
```
Откроет нативное окно Electron с кастомным заголовком в стиле Space Onyx (`#0D0D0E`).

### 4. Запуск тестов
```bash
npm test
```
Запустит тесты шифрования, алгоритмов очистки канцелярита и интеграционных API эндпоинтов.
