# ВАЙБЕРЫ // Chat-first Email Client for Gmail & Yandex

> **«Почта, которая выглядит и ощущается как мессенджер, но работает с вашими существующими ящиками Gmail и Яндекс.»**

Проект представляет собой кроссплатформенный клиент электронной почты нового поколения:
- **Desktop App (Windows / macOS / Linux):** полноценный 3-4 панельный интерфейс (в стиле Superhuman и Telegram Desktop) на Electron.
- **Mobile App & PWA (iOS / Android / Web):** адаптивный мобильный интерфейс с физическими свайпами в архив, карточками файлов и пузырями сообщений.
- **De-clutter Engine:** интеллектуальная срезка канцелярита («Добрый день», «Уважаемый...»), юридических дисклеймеров и сворачивание 50-строчных цитат в компактные аккордеоны.
- **Zero-Knowledge Backend:** сервер не сохраняет тексты и вложения писем, обеспечивая безопасную передачу и шифрование токенов AES-256-GCM.

## Архитектура монорепозитория

```
ладк/
├── packages/
│   ├── shared/    # Общие типы, Zod схемы и De-clutter Engine (срезка канцелярита и цитат)
│   ├── backend/   # Fastify v5 API, шлюзы Gmail/Яндекс, AES-256-GCM шифрование токенов и телеметрия
│   ├── client/    # React 19 + Vite + Tailwind: Desktop Pro (3 колонки) + Mobile Shell (iPhone 16 Pro)
│   ├── desktop/   # Нативное десктопное приложение Electron (Windows/macOS)
│   └── mobile/    # Мобильный проект React Native (Expo) с локальной базой данных WatermelonDB
├── code_artifact.html  # Интерактивный UI Flow & Design System Board (референс дизайна)
└── package.json        # NPM Workspaces конфигурация
```

## Быстрый запуск

### 1. Запуск бэкенда
```bash
npm run server
```
Сервер запустится на `http://127.0.0.1:3001` и подключит очереди синхронизации.

### 2. Запуск веб / мобильного клиента
```bash
npm run client
```
Клиент доступен в браузере: `http://localhost:5173/` (с авто-проксированием API на бэкенд).
- **Desktop Pro вид (3-4 колонки):** открывается автоматически на мониторах шириной от 1024px.
- **Mobile вид (iPhone 16 Pro):** доступен по переключателю в шапке или на мобильных экранах.

### 3. Запуск нативного десктопного приложения (Windows)
```bash
npm run desktop
```
Откроет нативное окно Electron с кастомным заголовком в стиле Space Onyx (`#0D0D0E`).

### 4. Запуск тестов
```bash
npm test
```
Запустит тесты шифрования, алгоритмов очистки канцелярита и интеграционных API эндпоинтов.
